# Блокировки пользователей

**Статус:** бэк готов, **UI нет**  
**Связано с:** [profile.md](profile.md), [chats.md](chats.md), [notifications.md](notifications.md)

---

## Зачем (продукт)

Пользователь может **закрыть контакт** с другим аккаунтом: не подписываться, не получать нежелательное взаимодействие. Сейчас правило работает **на сервере**; в приложении экрана блокировки **ещё нет**.

---

## Как задумано (модель)

| Правило | Смысл |
|---------|--------|
| Блок **направленный** | A заблокировал B |
| Follow при активной блокировке | **Запрещён** (ошибка `user_blocked`) |
| UI блокировки | Планируется: профиль, чат, список заблокированных |

---

## Что есть сейчас

- Таблица `profile_blocks` и проверки в `follow_user` на бэке.
- В Flutter: только **подписка / отписка**; вызовов `block_user` / `unblock_user` **нет**.
- Иконка «block» в UI используется в **записи** (другой смысл), не для соцграфа.

---

## Что увидит пользователь (когда сделаем UI)

1. На чужом профиле или в чате — **Заблокировать**.
2. В настройках — список заблокированных, **Разблокировать**.
3. Заблокированный не может подписаться; лента / чат — по продуктовым правилам v1 (скрытие контента — уточнить при реализации).

---

## Вне скоупа (пока)

- Любой экран блокировки в приложении.
- Жалобы / модерация контента.
- Блок «не показывать посты в ленте» без полной блокировки аккаунта.
