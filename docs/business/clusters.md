# Кластеры (коллекции на профиле)

**Статус:** актуально на сейчас  
**Для кого:** продукт / бизнес / дизайн  
**Не про:** SQL, RPC, cubit’ы  

---

## Цель

**Кластер** — коллекция на витрине профиля: обложка, название, описание и набор постов.

Пользователь группирует публикации по темам («Портфолио», «Маникюр», «Лето 2026»), а гости могут **отфильтровать** сетку постов по коллекции.

Кластеры **не заменяют** посты и **не видны** в городской ленте Event / на карте сами по себе — это слой **организации профиля**.

---

## Кто участвует

| Роль | Что делает |
|------|------------|
| Владелец профиля | Создаёт кластеры, архивирует / удаляет, кладет посты в коллекцию |
| Гость | Смотрит полоску коллекций, фильтрует сетку постов |
| Clover | Считает посты в коллекции, хранит обложку, синхронизирует фильтр сетки |

---

## Что такое кластер (для пользователя)

Карточка в горизонтальной полоске на профиле:

- **обложка** (одно фото);
- **название** (обязательно);
- **описание** (по желанию);
- **счётчик** — сколько «живых» постов в коллекции (например, «12 фото»).

Тап по карточке **не открывает** отдельный экран коллекции — он **фильтрует** сетку публикаций ниже. Повторный тап снимает фильтр.

---

## Связь с публикациями

```
Пост ──(0..1)──► Кластер
```

| Правило | Смысл |
|---------|--------|
| Пост без кластера | Нормально — лежит в общей сетке профиля |
| Пост в одном кластере | Максимум **одна** коллекция на пост |
| Ивент-пост | Может быть в кластере — витрина не отрезает посты с маркером |
| Удаление кластера | Посты **остаются**; связь с коллекцией снимается |
| Архив кластера | Коллекция пропадает с витрины; посты остаются в профиле |

Привязка поста к кластеру — **с экрана поста** (меню автора): «Привязать к кластеру» / «Отвязать от кластера».

При создании поста **нельзя** сразу выбрать кластер — только после публикации.

---

## Где видно

| Место | Что видно |
|-------|-----------|
| **Свой профиль** | Полоска кластеров + сетка; меню ⋯ на карточке (архив / удалить) |
| **Чужой профиль** | Та же полоска и фильтр; **без** меню управления |
| **Настройки → Архивы → Кластеры** | Архивированные коллекции |
| **Лента Event / карта** | Кластеры **не показываются** |

Счётчик **«Публикации»** в шапке — все живые посты, не число кластеров.

---

## Создание кластера

**Откуда:** свой профиль → **+** → **Добавить кластер**

**Шаги:**

1. Выбрать **одно фото** для обложки.
2. При необходимости подрезать в редакторе.
3. Ввести **название** (обязательно, до 120 символов).
4. По желанию — **описание** (до 500 символов).
5. **Создать** → прогресс на профиле → карточка появляется в полоске.

Новый кластер добавляется **в конец** полоски (порядок задаётся на бэке).

---

## Фильтр сетки на профиле

1. Пользователь тапает карточку кластера.
2. Сетка публикаций показывает **только посты этой коллекции**.
3. Повторный тап по той же карточке — **сброс**, снова все посты.

На чужом профиле фильтр работает так же, но без управления коллекциями.

---

## Посты в коллекции

### Положить пост в кластер

1. Открыть **свой** пост (из сетки профиля).
2. Меню **⋯** → **Привязать к кластеру**.
3. Выбрать коллекцию из списка активных кластеров.

Если кластеров ещё нет — подсказка создать кластер с профиля.

### Убрать из коллекции

Меню **⋯** на посте → **Отвязать от кластера**.

### Переместить в другой кластер

Отвязать → привязать к другому (отдельного «перенести» нет).

---

## Архив и удаление

### Архивировать (с профиля)

Меню **⋯** на карточке кластера → **Архивировать**.

- Коллекция **исчезает** из полоски на профиле.
- Посты **остаются** в профиле и в городских лентах (если были публичными).
- Счётчик постов в архиве сохраняет последнее значение.

### Архив кластеров (настройки)

**Настройки → Архивы → Кластеры**

| Действие | Эффект |
|----------|--------|
| **Разархивировать** | Коллекция снова в полоске профиля |
| **Удалить** | Кластер и обложка удаляются безвозвратно; посты остаются, связь снимается |

### Удалить с профиля (без архива)

Меню **⋯** → **Удалить** — сразу и навсегда (с подтверждением).

---

## Правила и ограничения

| Правило | Деталь |
|---------|--------|
| Только свой профиль | Создавать и управлять может только владелец |
| Одна обложка | При создании — одно фото |
| Счётчик постов | Автоматически; учитываются только **живые** посты (не в архиве поста, не удалённые) |
| Редактирование после создания | **Нет** отдельного сценария «изменить название / обложку» — только архив / удалить и создать заново |
| Перестановка карточек | **Нет** drag-and-drop в UI; порядок — по дате добавления |
| Сон аккаунта (hibernate) | Контент автора скрывается из городских лент; кластеры на профиле следуют общим правилам видимости |

---

## Что на экране есть / нет

| Есть | Нет (пока) |
|------|------------|
| Создание с обложкой, названием, описанием | Редактирование существующего кластера |
| Фильтр сетки по коллекции | Отдельный полноэкранный «альбом кластера» |
| Привязка / отвязка поста с деталки | Выбор кластера при создании поста |
| Архив и удаление | Drag-and-drop порядка карточек |
| Прогресс загрузки на профиле | Публичная ссылка «поделиться коллекцией» |

## Коротко одной схемой

```
Профиль → + → Добавить кластер
    └── обложка + название (+ описание) → карточка в полоске

Полоска кластеров
    ├── тап → фильтр сетки постов
    └── ⋯ (свой профиль) → архив / удалить

Пост (свой) → ⋯ → привязать / отвязать кластер

Настройки → Архивы → Кластеры → разархивировать / удалить
```
