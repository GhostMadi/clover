# Чаты и сообщения (как сейчас)

**Статус:** актуально на сейчас  
**Для кого:** продукт / бизнес / дизайн  
**Не про:** SQL, RPC, cubit’ы  

Техника (бэк): `docs/supabase/MIGRATIONS_INDEX.md` (раздел «Чат»), `supabase/migrations/_chat/README.md`  
Навигация: [navigation-bars.md](navigation-bars.md) · профиль: [profile.md](profile.md) · шаринг поста: [publications.md](publications.md)

---

## Цель

**Чат** — переписка между пользователями Clover **внутри приложения**.

Сейчас это **личные диалоги (DM)**: один на один, без публичных комментариев под постом и без внешних мессенджеров.

Дополнительно: **поделиться постом** — отправить превью публикации выбранным людям из подписок (отдельный сценарий, но сообщение попадает в тот же чат).

---

## Кто участвует

| Роль | Что делает |
|------|------------|
| Авторизованный пользователь | Видит список чатов, пишет, читает, делится постами |
| Собеседник | Тот же набор действий в общем диалоге |
| Clover | Хранит беседы и сообщения, доставляет в realtime, считает «прочитано» |

Без входа в аккаунт чаты **недоступны**.

---

## Где в приложении

| Откуда | Куда |
|--------|------|
| Нижний бар → **Chat** | Список «Сообщения» |
| Тап по строке чата | Экран переписки |
| **Чужой профиль** → иконка чата / **Сообщения** | Диалог с этим человеком (создаётся автоматически) |
| **Пост** → иконка «отправить» | Шторка «Поделиться» → выбор получателей из подписок |

Групповые чаты на бэке **заложены**; в UI — **создание группы** из списка «Сообщения» (участники из подписок).

## Список чатов («Сообщения»)

Экран вкладки **Chat**:

- заголовок **Сообщения**;
- **поиск по чатам** — фильтр по @username и тексту последнего сообщения (на клиенте);
- **поиск по тексту сообщений** — FTS на бэке: в списке чатов (раздел «В сообщениях») и внутри переписки (иконка 🔍);
- строки диалогов: аватар, имя, превью последнего сообщения, время;
- **непрочитанные** — подсветка строки; для входящих учитывается курсор прочитанного;
- pull-to-refresh.

Пустые состояния:

- **«Пока нет чатов»** — начните переписку с чужого профиля;
- **«Чаты не найдены»** — ничего не подошло под поиск.

## Открытие диалога

### Из списка

Тап по чату → загрузка истории → переписка.

### С профиля человека

1. Открыть **чужой профиль**.
2. Нажать **иконку чата** (если ещё не подписан) или **Сообщения** (если уже подписан).
3. Экран чата открывается **сразу**; беседа создаётся на сервере в фоне (`create_dm`).
4. Если переписки ещё не было — пустой чат с текстом «Напишите первое сообщение».

Повторное открытие того же человека ведёт в **ту же** беседу.

---

## Переписка (экран чата)

### Что видит пользователь

- шапка с **@username** собеседника;
- лента сообщений (свои справа, чужие слева);
- поле ввода и кнопка отправки;
- меню **+** у поля: **Фото** / **Документ** (см. ограничения ниже).

### Типы сообщений

| Тип | В UI сейчас |
|-----|-------------|
| **Текст** | ✅ основной сценарий |
| **Пост** (`post_ref`) | ✅ превью карточки; тап → экран поста |
| **Фото / медиа** | ✅ выбор и отправка через Edge Function |
| **Документ** | ✅ выбор файлов и отправка |
| **Системные** | только если пришли с бэка |

### Отправка текста

1. Ввести текст.
2. Нажать отправить.
3. Сообщение появляется **сразу** (оптимистично), затем подтверждается сервером.
4. При ошибке — snackbar, можно повторить.

### Прочитано

- У **исходящих** сообщений — индикатор «прочитано собеседником» (`read_by_peer`).
- При открытии чата курсор прочитанного **сдвигается вперёд** — собеседник видит галочки без перезагрузки (realtime).

### Кэш

История последнего диалога может показываться **из локального кэша** мгновенно, затем обновляется с сервера.

## Поделиться постом в чат

**Откуда:** любой пост → иконка **«отправить»** (share).

**Шаги:**

1. Открывается шторка **«Поделиться»**.
2. Список получателей — из **ваших подписок** (+ частые получатели, если есть история).
3. Можно выбрать **нескольких** людей.
4. По желанию — короткий текст к посту.
5. **Отправить**.

**Результат:**

- каждому получателю уходит сообщение с **превью поста** в вашем DM;
- если диалога не было — он создаётся;
- в списке чатов превью последнего сообщения: **«Пост»**;
- в переписке — карточка с обложкой; тап открывает пост.

Шаринг **только внутри Clover** — не ссылка в WhatsApp / Stories.

Счётчик **sends** у поста увеличивается при успешной отправке.

## Связь с профилем и подписками

| Ситуация | Поведение |
|----------|-----------|
| Не подписан на человека | На профиле — **Подписаться** + иконка чата |
| Уже подписан | **Сообщения** (широкая кнопка) + отписаться |
| Поделиться постом | Получатели — из **подписок**, не произвольный поиск по всему Clover |
| Свой профиль | Кнопки чата нет — писать себе нельзя |

## Правила и ограничения

| Правило | Деталь |
|---------|--------|
| Только авторизованные | Без Google-входа чат недоступен |
| DM в UI | Один диалог = два участника |
| Блокировки | На бэке заложены в social graph; отдельный UX «заблокировать в чате» не описан |
| Удаление сообщений | Свои текстовые — **удалить** (soft-delete на бэке) |
| Редактирование сообщений | Свои **текстовые** — изменить |
| Ответ (reply) | **Свайп** сообщения в сторону (входящие → вправо, исходящие → влево); цитата в пузыре |
| Реакции | **Long-press** → панель emoji снизу (как в Instagram); tap вне — закрыть |
| Пересылка / edit / delete | **⋯** на панели реакций или отдельное меню «Ещё» |
| «Печатает…» | Broadcast typing в realtime |
| Подгрузка истории | Скролл вверх — старые сообщения |
| Поиск по тексту всех сообщений | **Нет** (только фильтр списка чатов) |
| Push о новых сообщениях | **Не v1** |
| Вложения фото/файлов | Бэк и Storage готовы; клиентская отправка **не завершена** |
| Групповые чаты | Бэк поддерживает; UI создания **нет** |

## Что на экране есть / нет

| Есть | Нет (пока) |
|------|------------|
| Список DM, поиск по чатам | Push-уведомления |
| Текст, realtime, прочитано | — |
| Открытие с профиля без лишнего спиннера | Шаринг поста наружу |
| Шаринг поста подписчикам | — |
| Превью поста в пузыре | — |
| Локальный кэш треда | Удаление / редактирование сообщений |
| **Фото и документы** в сообщениях | — |
| **Реакции** (long-press → панель снизу) | — |
| **Групповые чаты** (создание из списка) | Админ UI (добавить/удалить участника) |
| **Поиск по истории** (FTS, текст) | Поиск по вложениям |
| **Ответ / пересылка / edit / delete** | Pin / mute / archive диалога |

## Коротко одной схемой

```
Нижний бар → Chat → список диалогов
    ├── тап → переписка (текст, превью поста)
    └── поиск по @ и последнему сообщению

Чужой профиль → чат / «Сообщения»
    └── create_dm → тот же диалог при повторе

Пост → Поделиться → подписки → post_ref в DM каждому

Realtime: новые сообщения + «прочитано» у исходящих
```
