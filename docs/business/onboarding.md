# Онбординг (как сейчас)

**Статус:** актуально на сейчас (контент итеративно дорабатывается)  
**Для кого:** продукт / бизнес / маркетинг  
**Не про:** код, анимации, хранилище флагов

---

## Цель

После входа быстро показать новому пользователю, **зачем Clover** и что можно делать: жизнь в городе, создание контента, чат, профиль и сервисы для бизнеса.

Онбординг не регистрирует и не проверяет личность — это уже сделала [аутентификация](authentication.md).

---

## Кто участвует

| Роль | Что делает |
|------|------------|
| Пользователь | Листает слайды, пропускает или завершает |
| Clover | Показывает 6 слайдов и ведёт в приложение |
| Бизнес / продукт | Задаёт тексты и смысл каждого слайда |

---

## Когда показывается

| Когда | Что происходит |
|-------|----------------|
| Первый вход (ещё не проходил) | После успешного входа открывается онбординг |
| Повторный вход / уже видел | Сразу на **главный экран** — онбординг **один раз** на аккаунт |
| Из настроек | Настройки → О приложении → можно **посмотреть снова** (replay; флаг «видел» не сбрасывается) |

---

## Что видит пользователь

Полноэкранная серия из **6 слайдов**. Можно листать вперёд, на последнем — начать пользоваться приложением. В любой момент — **Пропустить**.

На каждом слайде: иллюстрация, эмодзи, заголовок, короткий текст.

---

## Слайды (содержание)

### 1. Приветствие — зачем Clover

**Смысл:** Clover для яркой жизни и умного бизнеса.  
**Сообщение:** события, люди и сервисы — в одном месте.

### 2. Лента и карта

**Смысл:** находить, что происходит рядом.  
**Сообщение:** концерты, встречи, места; с Home можно быстро выйти на карту.

### 3. Создавай своё

**Смысл:** пользователь не только смотрит — он публикует.  
**Сообщение:** маркер на карте, пост с фото, реакции; город узнаёт о тебе.

### 4. Чат

**Смысл:** общение внутри Clover.  
**Сообщение:** писать организаторам, друзьям и клиентам без лишних приложений.

### 5. Профиль

**Смысл:** профиль как витрина.  
**Сообщение:** для гостя — лицо в городе; для бизнеса — живая витрина бренда.

### 6. Сервисы

**Смысл:** инструменты для бизнеса и удобство для гостей.  
**Сообщение:** онлайн-запись; бонусы настраиваются **на услуге** (начисление и оплата лояльностью) — см. [bonuses.md](bonuses.md).

---

## Основной сценарий: первый проход после входа

1. Пользователь успешно вошёл (сейчас — через Google).
2. Clover открывает онбординг.
3. Пользователь листает слайды (или пропускает).
4. На последнем слайде нажимает начать / завершить **или** жмёт «Пропустить» раньше.
5. Clover запоминает, что онбординг пройден (для этого пользователя).
6. Пользователь попадает на **главный экран** (дашборд: лента / карта / остальное).

---

## Сценарий: посмотреть снова

1. Пользователь уже в приложении.
2. Открывает **Настройки → О приложении**.
3. Запускает повторный просмотр онбординга.
4. Листает или пропускает.
5. Возвращается назад в настройки / туда, откуда пришёл (не «как будто первый вход»).

---

## Что пользователь может сделать на экране

| Действие | Результат |
|----------|-----------|
| Листать вперёд | Следующий слайд |
| Пропустить | Сразу в приложение (или назад, если смотрел повторно) |
| Завершить на последнем слайде | В приложение |

Назад по слайдам жестом / кнопкой — по возможности листания; отдельного «обязательного теста» нет: онбординг можно полностью пропустить.

---

## Результат для бизнеса

После онбординга пользователь понимает (хотя бы в общих чертах):

- Clover = городская жизнь + инструменты для бизнеса;
- есть лента и карта;
- можно создавать контент;
- есть чат;
- профиль важен как витрина;
- есть запись; бонусы живут на услугах.

Дальше ценность доказывается уже в самом приложении, а не на слайдах.

---

## Что пока не входит в этот процесс

| Тема | Статус |
|------|--------|
| Отдельные «tips» по сервисам (запись, бонусы и т.д.) внутри продукта | Задумано на будущее, не этот стартовый поток |
| Онбординг до входа (для гостя без аккаунта) | Нет — сначала вход |
| Разный онбординг для «только гость» и «только бизнес» | Пока один общий набор слайдов для всех |

```

```
