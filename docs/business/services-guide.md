# Гайд сервисов

**Статус:** актуально  
**Связано с:** [settings.md](settings.md), [booking.md](booking.md), [attendance.md](attendance.md), [resources-guide.md](resources-guide.md), [tag-powers.md](tag-powers.md)

---

## Зачем

Один вход **Настройки → Сервисы → Гайд**: коротко, как пользоваться **всеми** бизнес-сервисами Clover (Запись, Посещаемость, Ресурсы) — не только ресурсами.

Гайд объясняет смысл и шаги. Доступ к хабу сервиса по-прежнему через **тег** ([tag-powers.md](tag-powers.md)).

---

## Точка входа

| Откуда | Куда |
|--------|------|
| Настройки → **Гайд** | Хаб гайда (карточки сервисов) |
| Карточка сервиса в гайде | Экран гайда по ключу (`booking` / `attendance` / `resources`) |
| Ресурсы → тайл «Гайд» на обзоре | Углубление только по ресурсам ([resources-guide.md](resources-guide.md)) |
| Запись → Обзор → тайл «Гайд» | Концепция записи ([booking-guide.md](booking-guide.md)) |

Тайл **Гайд** в настройках **всегда** в блоке «Сервисы» (не только при теге `resources`).

---

## Карточки хаба

| Ключ | Заголовок | Суть |
|------|----------|------|
| `booking` | Запись | Услуги, inbox, расписание, приглашение исполнителя |
| `attendance` | Посещаемость | Компании, геозона, punch, работники |
| `resources` | Ресурсы | Местоположения и фильтры витрины |

Порядок: Запись → Посещаемость → Ресурсы.

---

## Содержание (кратко)

### `booking`

1. Тег `booking` на профиле открывает хаб хозяина.  
2. Заведите услуги и принимайте заявки в inbox.  
3. Клиент пишет вам / бронирует без вашего тега «Мои бронирования».  
4. Исполнителя можно пригласить в DM карточкой.

### `attendance`

1. Тег `attendance` (admin) / `attendanceWork` (worker).  
2. Создайте компанию, геозону, пригласите работников.  
3. Punch с телефона; аналитика и табель — у admin.

### `resources`

1. Тег `resources`.  
2. Местоположения для постов; фильтры витрины на профиле.  
3. Детали — [resources-guide.md](resources-guide.md).

---

## Правила

- Тексты на клиенте (ключи EN), не в Postgres.  
- Гайд не заменяет тег и не включает сервис «кнопкой».  
- Мобилка и сайт — одни ключи и смысл.

## Вне скоупа

- Гайд по бонусам / брони зала (пока нет в настройках-сервисах).  
- Видео-онбординг.
