Скопируй блок **«ПРОМПТ»** целиком в ChatGPT / Claude / Cursor.  
Места в `⟦ … ⟧` — **замени на своё**, остальное не трогай.

Эталон формата: [venue-plan.full.example.json](venue-plan.full.example.json) · контракт: [venue-plan-json.md](venue-plan-json.md)

## ПРОМПТ (копировать отсюда)

```
Ты генерируешь JSON схемы пространства для редактора Clover.
Ответ — ТОЛЬКО валидный JSON, без markdown-обёртки и без комментариев.

### Формат ответа (строго)
{
  "version": 1,
  "activeFloorKey": "floor_1",
  "floors": [
    {
      "id": "plan_floor_1",
      "floorKey": "floor_1",
      "label": "…",
      "version": 1,
      "status": "draft",
      "canvas": { "width": 1280, "height": 860, "background": "#F7F7F8" },
      "nodes": [ /* объекты ниже */ ]
    }
  ]
}

Если этажей больше одного — добавь floor_2, floor_3… и поставь activeFloorKey на нужный.

### Правила узлов (nodes)
kind (только эти): rect | ellipse | line | polygon | path | emoji | text
role:
  - "decor" — стены, бар, сцена, подписи, смайлы; bookableId = null; гость НЕ кликает
  - "bookable" — стол / кресло / зона / кабина; ОБЯЗАТЕЛЕН bookableId вида "bk_…"
Геометрия:
  - rect, ellipse, emoji, text → нужен frame: { x, y, w, h }
  - line → points: минимум 2 точки {x,y}
  - polygon → points: минимум 3
  - path → points; опционально holes: [[{x,y},…]] (дыры)
  - rotation — градусы, опционально
  - groupId — одинаковый у стола и его стульев (двигаются вместе)
style: { fill, stroke, strokeWidth, radius, opacity }
  - fill может быть null
  - для ellipse bookable часто radius: 999
zIndex: число (фон 0…1, декор 2–6, bookable ~10, подписи/emoji ~20)
Координаты в px внутри canvas; не вылезай за width/height без нужды.
НЕ клади inventory / free / held / taken внутрь nodes.
НЕ выдумывай другие kind.

Цвета ориентир (можно свои):
  bookable стол: fill "#FFA39E", stroke "#B54B45"
  VIP/фиолетовый: "#EDE9FB" / "#5C4FA8"
  зона: "#E3F0FC" / "#5B9BD5"
  декор серый: "#E8E8E8" / "#CCCCCC"
  сцена тёмная: "#1A1D1E"

### Что нарисовать — МОИ ДАННЫЕ (заполнил человек)

Тип места: ⟦например: кафе / кино / ресторан / коворкинг / банкетный зал⟧
Название на плане: ⟦например: Кафе Абая⟧
Число этажей: ⟦1 или 2⟧
Размер холста (если не уверен — оставь 1280×860): ⟦ширина⟧ × ⟦высота⟧

Планировка словами (обязательно подробно):
⟦
Опиши зал: где вход, бар, кухня, сцена, туалет.
Сколько столов / рядов кресел / зон и как они стоят (слева/справа/у окна).
Что бронируется (столы? кресла? зоны?), что только декор.
⟧

Числа (подставь свои):
- Бронируемых объектов примерно: ⟦например: 12 столов⟧
- Вместимость типичного стола/места: ⟦например: 2–4⟧
- Особые места: ⟦например: 1 VIP, 1 лаунж-зона, кабина⟧

Стиль:
⟦светлый кафе / тёмный кинозал / праздничный банкет⟧

Дополнительно:
⟦что угодно ещё: «столы с groupId и 2 стула», «emoji у WC», «подпись у входа»⟧

### Обязательно используй по возможности
Хотя бы по одному: rect, ellipse, line, text, emoji.
Если уместно — polygon (зона) и path (контур/стены).
У bookable — уникальные bookableId (bk_table_1, bk_vip, …).
Подписи text/emoji на русском или как в моём описании.

Сгенерируй полный JSON сейчас.
```

## Пример: как заполнить ⟦ … ⟧

| Плейсхолдер | Пример «от себя» |
|-------------|------------------|
| Тип места | ресторан |
| Название | Sushi House на Достык |

| Планировка | Вход снизу. Слева бар. Справа 8 прямоугольных столов в 2 ряда. У окна 2 овальных VIP. Сзади сцена-декор. WC справа emoji. |
| Бронируемых | 10 столов |

| Стиль | светлый кафе |
