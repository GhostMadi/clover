# Гайд сервиса «Запись» (внутри хаба)

**Статус:** актуально  
**Связано с:** [booking.md](booking.md), [booking-points.md](booking-points.md), [services-guide.md](services-guide.md), [website-host-desktop.md](website-host-desktop.md)

---

## Зачем

В хабе **Запись** (обзор точки) — один тайл **Гайд**: коротко, **какие функции** в сервисе.

Общий гайд всех сервисов — [services-guide.md](services-guide.md). Здесь — только Запись внутри workspace.

## Точка входа

| Откуда | Куда |
|--------|------|
| Запись → Обзор → тайл **Гайд** | `/app/settings/booking/p/[pointId]/guide` |
| Настройки → Гайд → Запись | общий вход ([services-guide.md](services-guide.md)) |

Гайд **не** в rail навигации.

## Содержание

**Идея.** Кабинет хозяина точки: услуги, заявки и общие настройки расписания.

1. **Записи** — входящие заявки и день точки: подтвердить, перенести, отметить визит.
2. **Услуги** — что можно забронировать: название, длительность, цена, кто принимает.
3. **Аналитика** — сводка по периоду: записи, статусы, нагрузка.
4. **Настройки** — правила выбранной точки: часы, выходные, горизонт, отмена, блокировки.

## Правила

- Без тега `booking` хаб недоступен.
- Текст — функции разделов; детали — в самих экранах.
