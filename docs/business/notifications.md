# Уведомления (in-app)

**Статус:** актуально на сейчас  
**Для кого:** продукт / бизнес / дизайн  
**Не про:** SQL, RPC, cubit’ы  

Техника (бэк): [SPEC_IN_APP_NOTIFICATIONS.md](../supabase/SPEC_IN_APP_NOTIFICATIONS.md)  
Запись (связанный процесс): [booking.md](booking.md) · [bonuses.md](bonuses.md)

---

## Зачем

Единая **лента событий** для пользователя: реакции на контент, подписки, запись к мастеру.  
Открывается с **Home → колокольчик**; непрочитанное — **точка на колокольчике**.

Push на заблокированный телефон — для **чата** уже в скоупе (FCM).  
Для соц/записи lock-screen push — по мере готовности outbox; in-app лента колокольчика — отдельно.

---

## Точка входа

| Откуда | Куда |
|--------|------|
| Home (Event / Map) → **колокольчик справа** | Экран «Уведомления» |
| Бейдж на колокольчике | Есть хотя бы одно непрочитанное за последние **30 дней** |

После открытия ленты непрочитанные помечаются прочитанными (mark read).

---

## Общие правила

| Правило | Как |
|---------|-----|
| **Тексты** | На **клиенте** по `kind` + данным (имя actor, пост, услуга, время). Бэк не хранит русские фразы |
| **Срок** | В ленте только **30 дней** |
| **Actor** | Кто инициировал событие (лайкнул, подписался, записался, отменил…) |
| **Self** | Себе не шлём (лайк своего поста и т.п.) |
| **Блок / hibernate** | `notifications_should_deliver` — не доставляем, если нельзя взаимодействовать |

## Социальные уведомления

### Реакции и комментарии

| Событие | Кому | Что видит |
|---------|------|-----------|
| Лайк поста | Автор поста | «@user лайкнул ваш пост» + превью |
| Дизлайк поста | Автор поста | «… дизлайкнул …» |
| Комментарий к посту | Автор поста | «… прокомментировал …» + превью коммента |
| Ответ на коммент | Автор родительского коммента | «… ответил(а) на ваш комментарий» |
| Лайк / дизлайк коммента | Автор коммента | «… лайкнул ваш комментарий» |

**Тап** → экран поста.

Убрал реакцию / удалили коммент → уведомление **снимается** (dedupe).

### Подписки

| Событие | Кому | Что видит |
|---------|------|-----------|
| Новый подписчик | Владелец профиля | «@user подписался(-ась) на вас» |
| Взаимная подписка | То же | «… Вы подписаны друг на друга» |

**Кнопка «Подписаться»** / «Подписаны» прямо в плитке (если ещё не подписан).  
**Тап** по плитке (не по кнопке) → **чужой профиль** подписчика.

Подписка оформляется через соцграф (`follow_user`), уведомление пишется в общую таблицу `notifications`.

## Уведомления по записи

Instant booking: запись **сразу подтверждена**, отдельного «хозяин одобрил заявку» **нет**.

| Событие | Кому | Зачем |
|---------|------|-------|
| Новая запись | **Хозяин** | Клиент забронировал слот |
| Вы записаны | **Клиент** | Подтверждение брони |
| Напоминание о визите | **Клиент** | За **24 ч**, **3 ч**, **1 ч**, **30 мин** до начала (in-app; cron каждые 15 мин) |
| Визит начался | **Хозяин** | Отметить «клиент пришёл» |
| Пора закрыть визит | **Хозяин** | «Оказана» / «Не пришёл» — иначе бонусы не начислятся честно |
| Отмена | **Вторая сторона** | Кто отменил — виден в actor |
| Оказана (+ бонусы в тексте) | **Клиент** | Итог визита |
| Не пришёл | **Клиент** | Статус no-show |

**Тап:** хозяин → **Настройки → Запись** (inbox); клиент → **⋯ → Мои бронирования**.

Подробнее про запись и визит: [booking.md](booking.md).  
Про бонусы после «Оказана»: [bonuses.md](bonuses.md).

## Чат (не колокольчик)

Новое **входящее сообщение** — не строка в ленте колокольчика Home.

| Где | Что видит |
|-----|-----------|
| Вкладка **Chat** (бейдж) | Есть непрочитанные сообщения чата |
| Список «Сообщения» | Live-превью / unread (см. [chats.md](chats.md)) |
| Другой экран / фон | **Push** (title = @ник или «Чат», body = текст/«Фото»/«Пост») |
| Приложение открыто, не в этом треде | Заметный верхний баннер (ник + превью, тап → чат) |

**Тап** по push или баннеру → **экран переписки** этого диалога.

Себе (своим исходящим) push **не** шлём.
