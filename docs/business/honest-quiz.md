# Честный тест (временно)

**Статус:** временная шутка / мини-игра на сайте. **Не** часть продукта Clover.  
**Убрать:** удалить маршрут `web/src/app/honest/`, фичу, миграцию/таблицу, строку в каталоге.

## Зачем

Короткий «честный тест» для девушки: кнопки «НЕТ» убегают, финал ради фото, потом «спасибо».  
Ответы пишутся в бэк; смотреть — в админке `/honest/admin`.

## Ссылка для неё

`https://clover.com.kz/honest`  
(локально: `http://localhost:3000/honest`)

## Админка

Ответы: `/admin/honest` (вход через обычную админку сайта `/admin`).  
Секрет RPC: env `HONEST_QUIZ_ADMIN_SECRET` или дефолт `clover-honest-temp-2026` (см. SPEC).

## Фазы игры

1. «Я тебе нравлюсь?» — ДА / НЕТ (НЕТ убегает)  
2. «Ты меня любишь?» — ДА / НЕТ (НЕТ прыгает)  
3. «Скинь фотку» — СКИНУ / НЕ СКИНУ → загрузка фото → финал «Спасибо»
