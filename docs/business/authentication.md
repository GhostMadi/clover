# Аутентификация (как сейчас)

**Статус:** актуально на сейчас  
**Для кого:** продукт / бизнес / онбординг команды  
**Не про:** код, API, Edge Functions, секреты

---

## Цель

Пользователь должен безопасно войти в Clover и попасть в приложение под своим аккаунтом.

---

## Кто участвует

| Роль | Что делает |
|------|------------|
| Пользователь | Открывает приложение и входит |
| Clover | Показывает экран входа, создаёт/узнаёт аккаунт, пускает дальше |
| Google | Подтверждает личность пользователя (единственный способ входа **сейчас**) |

---

## Что видит пользователь сейчас

На экране входа один рабочий способ:

**«Continue with Google»**

Входа по номеру телефона / WhatsApp / коду из SMS в приложении **пока нет** (готовится отдельно, пользователю не предлагается).

---

## Основной сценарий: вход через Google

1. Пользователь открывает Clover.
2. Если он ещё не вошёл — видит экран входа с логотипом Clover и кнопкой Google.
3. Нажимает **Continue with Google**.
4. Выбирает / подтверждает свой Google-аккаунт (как обычно на телефоне).
5. Clover узнаёт пользователя:
   - если человек новый — создаётся аккаунт и профиль;
   - если уже был — открывается существующий аккаунт.
6. После успешного входа пользователь идёт в **онбординг** (сейчас показывается после входа; позже можно показывать только один раз).
7. Дальше пользователь пользуется приложением как авторизованный.

---

## Повторный вход

Если пользователь уже входил и сессия сохранилась:

1. Открывает приложение.
2. Не видит экран входа заново.
3. Сразу попадает дальше (сейчас — снова через онбординг, пока он не «зафиксирован» как пройденный).

---

## Выход

Пользователь может выйти из аккаунта в настройках / профиле (стандартный logout).  
После выхода снова показывается экран входа.

---

## Ошибки (что бывает у пользователя)

| Ситуация | Что происходит |
|----------|----------------|
| Закрыл окно Google / отменил вход | Остаётся на экране входа, без аккаунта |
| Сбой сети / Google недоступен | Сообщение об ошибке, можно попробовать снова |
| Google Sign-In не настроен на стороне продукта | Сообщение, что вход через Google не удался |

OTP, пароли и коды по SMS пользователь **сейчас не вводит**.

---

## Что получается на выходе

- Один аккаунт Clover на человека (через Google).
- Профиль пользователя в приложении.
- Доступ к ленте, карте, чатам, профилю и остальным разделам после входа.

---

## Что пока не входит в этот процесс (но рядом)

| Тема | Статус с точки зрения бизнеса |
|------|-------------------------------|
| Вход по телефону / WhatsApp с кодом | В подготовке; в приложении пользователю ещё не показывается |
| Отдельный «логин по паролю» | Нет |
| Несколько способов входа на одном экране | Пока только Google |

Когда телефонный вход включат для пользователей — опишем отдельным процессом и свяжем с этим файлом.

---

## Связанные процессы

- [Онбординг](onboarding.md) — сразу после успешного входа
- Профиль — создаётся / открывается при первом и повторном входе

---

## Коротко одной схемой

```
Пользователь
    → экран входа Clover
    → Continue with Google
    → подтверждение в Google
    → аккаунт Clover (новый или существующий)
    → онбординг
    → приложение
```
