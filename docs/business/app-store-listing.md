## Privacy Nutrition Labels (ориентир для анкеты Apple)

Отмечай только то, что реально собираете. Типично для Clover сейчас:

| Категория | Примеры | Зачем |
|-----------|---------|--------|
| Contact Info | email, телефон (если указан), имя/ник | аккаунт |
| User Content | посты, фото, комментарии, чаты | сервис |
| Identifiers | user id, device / push token | аккаунт, уведомления |
| Location | точная / приблизительная при разрешении | карта, геозона посещаемости |
| Diagnostics | логи сбоев (если есть) | стабильность |

**Не продаём** данные. Данные могут уходить провайдерам инфраструктуры (хостинг БД, хранилище файлов, карты, push, вход Google) — для работы сервиса, не для продажи рекламным сетям Clover.

Уточни в Connect по факту: рекламные SDK / трекинг сторонних рекламных сетей — если **не** подключены, не заявляй «Used for Tracking».
