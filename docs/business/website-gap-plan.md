## Детали шагов

### 1 — Лента города + фильтры
RPC `list_events_feed_enriched_cursor`. Фильтры v1: страна/город + «Все / Ивенты» (ключи EN). Сетка с `__ar-WxH`.

### 2 — Деталь поста + чужой профиль
`/app/u/[userId]` — чужой профиль + follow. `/app/posts/[id]` — деталь (из сетки профиля), RPC `get_post_enriched`.

### 3 — Карта
Тап маркера → шторка поста. «Моя геолокация». Фильтры: страна/город + эмодзи + теги → `list_markers_map`.

### 4 — Профиль полный
Edit, создание поста, **кластеры** (полоска-фильтр, создание с обложкой, ⋯ архив/удалить, привязка поста, архив в settings), settings hub, подписки.

### 5 — Соц вокруг поста
Комменты (шторка), реакции и закладки в ленте/посте, сохранённые (`/app/settings/saved`).

### 6 — Чаты
DM + вложения + FTS («В сообщениях» + поиск в треде) + создание группы из недавних пиров. Админ участников / FTS polish — позже.

### 7 — Уведомления
`/app/notifications` + колокольчик в rail (бейдж unread). RPC `list_notifications_enriched_cursor` + пагинация скролла + `mark_notifications_read`. Deep-link на пост/профиль — частично.

### 8 — Бизнес-сервисы
- **8a Ресурсы** (сирень): хаб → местоположения + фильтры витрины + ярлык сбоку + чипы на витрине + привязка в посте — 🟡

- **8c Бонусы** — поля на услуге уже есть; полный клиентский UX лояльности позже · ❌

## 8d — Посещаемость на вебе

**Продукт (один процесс):** [attendance.md](attendance.md) · **хвосты сайта:** [website-attendance-gaps.md](website-attendance-gaps.md) · **бэк:** [SPEC_ATTENDANCE_SYSTEM.md](../supabase/SPEC_ATTENDANCE_SYSTEM.md) · мобилка: `lib/feature/_attendance_/`

> Процесс и правила — только в `attendance.md`. Список «что на сайте ещё не сделали» — в `website-attendance-gaps.md`.

### Главное решение

| | Веб | Мобилка |
|--|-----|---------|
| **Admin** | Полное управление (компании, люди, табель, OT, ЗП) | То же + операционка |
| **Worker** | **Read-only:** компании, часы, история отметок, отсутствия, превью ЗП | То же **+ punch / GPS** |
| **Не делаем на вебе** | Punch, гео-проверка, sheet «надо отметиться», outbox punch | — |

Admin на вебе + worker на телефоне (один аккаунт) — ок: веб смотрит управление и свои детали, телефон отмечает.

**Следствия UX**

- Settings → **Посещаемость** → admin-хаб (`/app/settings/attendance`); если есть membership — ссылка **«Моя посещаемость»**.
- Worker (и admin-как-сотрудник): `/app/attendance` — список компаний; `/app/attendance/w/[id]` — детали (без «Отметиться»).
- Ярлык сбоку: admin → admin-хаб; только worker → `/app/attendance`.
- На карточках worker: баннер «Отмечайтесь в приложении», **нет** CTA punch.
- Chat invite / accept на сайте ок; punch — нет.

Акцент: `service="attendance"` (синий). Код: `web/src/features/attendance/`.

### Фазы admin (A0–A7) — ✅

| Фаза | Что | Статус |
|------|-----|--------|
| **A0–A7** | Хаб, компания, настройки, работники, смены, табель, аналитика, ЗП | ✅ |

### Фазы worker read-only (W0–W1)

| Фаза | Что | Routes | Статус |
|------|-----|--------|--------|
| **W0** Worker-хаб | Список memberships; смена/дежурство; мини-статы; без punch | `/app/attendance` | ✅ |
| **W1** Мои детали | Часы месяца, дни, отсутствия, история отметок, превью ЗП | `/app/attendance/w/[id]` | ✅ |

### Вне 8d (веб)

- Punch UI, GPS, «надо отметиться», offline outbox punch  
- Live-трекинг, face ID, CRM-касса  
- Manager-роль между admin и worker  
- Пиксель-паритет Flutter
