# Фон чата — смайлики (wallpaper)

**Статус:** актуально (общий для всех участников)  
**Связано с:** [chats.md](chats.md)  
**Бэк:** колонка `chat_conversations.wallpaper_emojis` · RPC `get_conversation_wallpaper` / `set_conversation_wallpaper`

---

## Зачем

Участники украшают **фон переписки** смайликами: они разбросаны по фону (ваibe «жвачка / мультик»), не мешая читать сообщения.  
Фон **один на диалог** — видят все участники на всех устройствах (mobile + web).

## Участники / роли

| Роль | Что |
|------|-----|
| Любой участник чата | Может задать / сбросить фон (last-writer-wins) |
| Не участник | Не читает и не пишет wallpaper |

## Сущности

- `chat_conversations.wallpaper_emojis` — `text[]`, до **8** уникальных grapheme
- Ключ: только `conversation_id` (пока чата нет — фон недоступен)

## Жизненный цикл

| Фаза | Как |
|------|-----|
| Открыть | **Инфо чата** → «Фон чата» (кисточка); клиент читает `get_conversation_wallpaper` |
| Задать | Ввод смайликов → `set_conversation_wallpaper` → broadcast `wallpaper_changed` |
| Действовать | Все открытые клиенты обновляют фон; позиции стабильны по seed |
| Сбросить | Пустой набор → чистый фон у всех |
| Logout | Локальный кэш wallpaper сбрасывается с account data (`chat_wallpaper_`); правда — на бэке |

## Карта экранов

Переписка → тап по шапке → **Инфо** → «Фон чата» → шторка (превью + поле + сохранить / убрать).
В шапке переписки кисточки **нет** — только в инфо.

## Стыки → решения

| Тема | Решение |
|------|---------|
| Sync / собеседник | ✅ Общий на conversation |
| Mobile ↔ web | Один RPC / одно поле |
| Локальный кэш | ✅ Как сообщения: `ChatLocalCache` → мгновенный paint, потом тихий sync с RPC |
| Фото фоном | Вне скоупа |
| Кто меняет в группе | Любой участник (как сейчас по продукту) |

## Правила

- Макс. **8** уникальных смайликов.
- Позиции детерминированы от `conversationId` + набора.
- Низкая непрозрачность — фон не спорит с bubble.

## Вне скоупа

- Общий wallpaper на все чаты сразу
- GIF / Lottie фон
- Права «только admin группы»
