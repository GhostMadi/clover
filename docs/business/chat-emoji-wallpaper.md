# Фон чата — смайлики (wallpaper)

**Статус:** MVP (локально на устройстве)  
**Связано с:** [chats.md](chats.md)

---

## Зачем

Пользователь украшает **фон переписки** своими смайликами: они разбросаны по фону в разных местах (ваibe «жвачка / мультик»), не мешая читать сообщения.

## Участники

- Владелец аккаунта — настраивает фон **у себя** в этом чате.

## Сущности

- **Набор смайликов** (1–8 уникальных grapheme) на диалог.
- Ключ диалога: `conversationId` (или peer/username, пока чат ещё создаётся).

## Жизненный цикл

| Фаза | Как |
|------|-----|
| Открыть | В шапке чата — иконка палитры → «Фон чата» |
| Задать | Ввести/вставить смайлики → сохранить |
| Действовать | Фон рисует смайлики в разбросе (стабильные позиции по seed) |
| Сбросить | «Убрать фон» → снова чистый фон |
| Logout | Локальные prefs фона чистятся с account-данными |

## Карта экранов

Переписка → (AppBar) палитра → шторка «Фон чата» (превью + поле смайликов + сохранить / сбросить).

## Стыки → решения

| Тема | Решение |
|------|---------|
| Sync между устройствами | **Нет** в MVP — только локально |
| Видит ли собеседник фон | **Нет** — только у себя |
| Фото / картинки фоном | Вне скоупа |
| Бэк / RLS | Не нужен |

## Правила

- Макс. **8** уникальных смайликов.
- Позиции детерминированы от ключа чата + набора (не прыгают при скролле).
- Низкая непрозрачность / размер — фон не спорит с bubble.

## Вне скоупа

- Общий wallpaper для всех чатов сразу
- GIF / Lottie фон
- Серверный sync
